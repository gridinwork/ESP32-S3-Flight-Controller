# BOM FC-ESP32 — отличия от FC-STM32

ESP32-S3-WROOM-1-N16 (C2913199) вместо H743 + кварца; те же датчики U2–U5; TJA1051 (CAN/TWAI); XC6220 ×2 (модуль ≥ 1 А, датчики); USB-C на GPIO19/20; кнопки BOOT/RESET; SD по 1-бит SDMMC; разъёмы как у FC-STM32 минус TELEM2/UART8/UART3 (нет UART), плюс те же ESC-гребёнки.

_25.11.2026: гребёнки J12A/B/C — штыревые PZ254V-11-08P (C492407) вместо гнездовых C9900015386 (как на FC-STM32)._
